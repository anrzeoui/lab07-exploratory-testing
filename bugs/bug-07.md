# BUG-07: «Хуучин хувилбар» холбоос HTTP 500 алдаа буцааж байна

**Орчин:** «Уншлагын жагсаалт» v2.0; багшийн `app.js`; бодит шалгалтад Node.js v22.16.0, Chromium 144.0.7559.96 (headless), 2026-10-20.  
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан, анхны **3 номтой** төлөв.  
**Статус:** `Reproduced — automated browser/API check` 

## Дахин гаргах алхам

1. Аппыг шинээр асаана.
2. Footer хэсгийн «Хуучин хувилбар» холбоос `/old` руу зааж байгааг харна.
3. Холбоосоор шилжиж хуудасны статусыг шалгана.
4. API түвшинд `curl -i http://localhost:3000/old` ажиллуулж нотолгоо авна.

## Хүлээгдэж байсан

Хуудас амжилттай ачаалж, серверийн 500 алдаа гарахгүй.

## Бодит ажиглалт

`GET /old` нь `HTTP/1.1 500 Internal Server Error` болон `Internal Server Error` текст буцаасан.

## Ноцтой байдал

**Major** — Дэлгэц дээрх линкээр хэрэглэгч нэвтрэхэд серверийн алдаа гарна.

## Олдсон аялал / хэрэглэсэн арга

**Saboteur / Supermodel**-ын тестийн санаагаар хийсэн автомат баталгаажуулалт.
