# BUG-08: Буруу JSON-д HTTP 400 биш 200 OK буцааж байна

**Орчин:** «Уншлагын жагсаалт» v2.0; багшийн `app.js`; бодит шалгалтад Node.js v22.16.0, Chromium 144.0.7559.96 (headless), 2026-10-20.  
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан, анхны **3 номтой** төлөв.  
**Статус:** `Reproduced — automated browser/API check` 

## Дахин гаргах алхам

1. Аппыг шинээр асаана.
2. Тусдаа терминалд `curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" --data-binary '{bad json'` ажиллуулна.
3. HTTP status болон JSON body-г уншина.

## Хүлээгдэж байсан

Malformed JSON хүсэлтэд HTTP 400 статус буцаана.

## Бодит ажиглалт

`HTTP/1.1 200 OK` болон `{"result":"OK"}` буцаасан.

## Ноцтой байдал

**Major** — API алдаатай хүсэлтийг амжилттай мэт мэдээлж интеграцийн тест болон хэрэглэгчийн талын алдаа боловсруулалтад нөлөөлнө.

## Олдсон аялал / хэрэглэсэн арга

**Saboteur**-ын тестийн санаагаар хийсэн автомат баталгаажуулалт.
