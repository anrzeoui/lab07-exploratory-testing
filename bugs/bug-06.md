# BUG-06: «Нийт ном» тоолуур бодит мөрийн тооноос нэгээр их байна

**Орчин:** «Уншлагын жагсаалт» v2.0; багшийн `app.js`; бодит шалгалтад Node.js v22.16.0, Chromium 144.0.7559.96 (headless), 2026-10-20.  
**Урьдчилсан нөхцөл:** `node app.js`-ийг шинээр асаасан, анхны **3 номтой** төлөв.  
**Статус:** `Reproduced — automated browser/API check`

## Дахин гаргах алхам

1. Аппыг шинээр асаана.
2. Хүснэгтэд хэдэн ном байгааг тоолно.
3. Хүснэгтийн доод хэсгийн «Нийт ном» тоог харна.
4. Хоёр утгыг харьцуулна.

## Хүлээгдэж байсан

Нийт ном = хүснэгт дэх номын тоо = 3.

## Бодит ажиглалт

Хүснэгтэд 3 мөр, «Нийт ном: 4» гэж гарсан.

## Ноцтой байдал

**Minor** — Жагсаалтын тоон үзүүлэлт худал гарч мэдээллийн найдвартай байдлыг сулруулна.

## Олдсон аялал / хэрэглэсэн арга

**Fed-Ex**-ын тестийн санаагаар хийсэн автомат баталгаажуулалт.
